# HowHub · 图文教程与攻略发布平台

## Agent 跨站事实核查汇总与可选离线 KaTeX（2026-11-06）

**原始资料多源证据汇总**：每条原创教程的具体可核查主张，后台现在独立显示「多个不同已批准域名的原文支持线索 / 仅单一来源支持 / 存在矛盾 / 全部证据过期 / 证据不足」。同一网站的多篇资料仅算一个来源；任何一份当前有效的冲突文档优先提示冲突。原始证据的有效期默认 30 天（可在后台设为 7–180 天），过期记录或被管理员禁用的网站不再作为**当前有效的交叉支持**，但原始历史记录仍可供管理员审计。即使汇总显示两个来源支持也只说明文档文字相近，**不代表已经确认事实真实，更不会自动放行或发布教程**。

**自动核查调度修复**：新增每篇原创教程的「最近规划时间 / 审稿版本」记录。若搜索索引根本没有匹配已批准站点，不再每个调度周期反复规划同一文章，最早在 24 小时后复查，以便新批准站点被考虑。旧版队列中的任务会保守处理；二次审稿变更后，过时主张的待核查任务停止调度，并对新版本重新进行有限的来源规划。相关状态可在后台查看，自动核查默认仍关闭。

**本地离线 KaTeX 公式（可选）**：HowHub 内置受控 TeX→MathML 仍保留。若需要更高保真公式，可在项目根目录安装固定版本的 KaTeX；安装完全不改变原先 PHP 页面或后台计划任务。管理员再进入「原创选题 Agent → 本地 KaTeX」开启。公式由服务器上受限的 Node.js 子进程离线生成 MathML，不加载第三方网页 JavaScript/CDN；TeX 最大 1900 字节、宏展开次数至多 64、用户尺寸至多 8em、处理时长上限 5 秒、trust=false，不支持访问外部 URL 或任意用户宏定义。输出再次经过 HowHub HTML 安全清洗。失败、未安装或管理员关闭时，自动退回原内置 MathML 解析器，并保留原始可编辑公式源码。KaTeX 覆盖更多 LaTeX 语法，但仍不能保证所有宏包的像素级 1:1。

Ubuntu / 宝塔服务器可按需要安装（先确认服务器 Node 版本和磁盘空间）：

    sudo apt-get install -y nodejs npm
    cd /www/wwwroot/howhub.k2n.cn/HowHub
    npm install --omit=dev --ignore-scripts --no-audit --no-fund
    php bin/agent-check.php

若 Node 不在 /usr/bin/node 或 /usr/local/bin/node，可在 PHP 运行环境通过 HOWHUB_NODE_BIN 配置 Node 可执行文件的绝对路径。线上使用不需要开启 KaTeX 即可继续正常生成教程。无需在每次更新时强制重新安装 Node 依赖；但升级 KaTeX 版本时应重新验证安全配置与 CI。供应商视频、完整 Mermaid 语法、事实真实性与线上多媒体链路仍需专用实测，并未因此自动通过。

## Agent 进一步开发：受控自动事实核查、高清导图与长视频文件（2026-11-06）

**自动核查受控来源（默认关闭）**：在后台原创选题 Agent 中启用后，针对二次审稿仍存在疑问的教程，使用原有搜索索引证据寻找管理员登记且启用的站点。每篇最多 4 个待核查任务，每一主张最多 2 个不同站点；每 24 小时默认 2 次、可调到 8 次。执行前检查 robots.txt、站点/同页冷却与全局频率预算，不访问尚未批准的网站，也不绕过登录、付费墙和拒绝访问指示。只保留管理员可见的出处网址、受限原文节选、SHA-256 与独立审稿观点，不下载第三方音视频，不把原文复制到文章。AI 即使判断“支持”，也不自动发布文章、不把结果标记成真实世界的事实认证。

**更丰富的安全公式**：原生 MathML 新增分段函数 cases、aligned/gathered 多行方程、根指数、向量与上划线、常见数学符号和黑板粗体数集。未知宏仍原样保留编辑，不执行外部 LaTeX/JS。仍未实现全部 LaTeX 的像素级高保真还原。

**本地高保真流程图 PNG（默认关闭）**：可选安装 Graphviz（dot）。从严格解析的原创 Mermaid 分支流程图或缩进型思维导图构建全新、安全的 DOT 节点/边关系，再在本地生成真实连线 PNG 并存储到本站图片库。编辑器继续保留原始 Mermaid 与 HTML 预览；不运行来源脚本、外部 Mermaid/SVG 或任意 shell 命令。可由管理员按篇触发，或打开自动生成，每天默认最多 4 张。未安装 Graphviz 时原有 HTML 关系图仍可使用。此功能不是通用 Mermaid 语法的完全一比一复制。

**更长的 AI 视频流式下载（需外部供应商实际兼容）**：新建视频任务可选择 4、8、12、16、20、30、60、90 或 120 秒目标时长，以及横屏 1280x720、竖屏 720x1280、1920x1080 尺寸。目标时长与容量在任务创建时持久化。供应商返回的视频文件通过有大小限制的私有临时磁盘流式下载，按 MP4 文件头与长度验证后转存本站素材库；单文件 1–128MB（默认 18MB），媒体播放器的 HTTP Range 支持最高 128MB。不会把较长 MP4 一次性全部装入 PHP 内存。供应商并非一定支持对应时长、尺寸、计费和编码格式，尚须实机验证。

Ubuntu 依赖示例：

    sudo apt-get install -y graphviz ffmpeg fonts-noto-cjk

使用已有安全更新流程：

    sudo bash bin/update.sh
    php bin/agent-check.php

CI 已加入或更新：站点审批范围、robots 访问预算、自动事实核验、图形白名单与真实 Graphviz PNG、复杂 MathML、视频参数快照及超过旧 18MB 限制的私有文件归档测试。线上搜索/视频模型与真实站点访问仍需部署后验收。

## 异步 AI 视频模型和原始来源事实核查（2026-11-06）

**异步视频生成（默认关闭）**：在后台「内容发现 Agent → 原创选题 Agent → 真实 AI 视频模型」配置独立供应商 URL（必须以 /v1 结尾）、加密 API Key、实际可用的视频模型 ID、JSON 或 multipart 提交格式与每日创建额度（默认 1，最高 4）。兼容协议依次为 POST /v1/videos 创建任务、GET /v1/videos/{id} 查看状态、GET /v1/videos/{id}/content 获取 MP4；每次 Agent 定时任务只执行一次阶段操作，最低约 90 秒到 120 秒冷却。独立视频生成不读取原文章，仅使用本站 AI 独立撰写的标题与步骤生成概念动画，并保存到本站私有附件库。默认单文件上限为 18MB，现可为新任务配置为最高 128MB，使用私有磁盘流式接收和播放器分段读取；强制校验任务 ID、文件类型、HTTP 状态和访问权限。

重要：OpenAI 官方 Sora Videos API 已于 2026-09-24 停用，因此不能把 Sora 当作默认可用的生产接口。本功能仅适配**仍提供这一协议形状的兼容视频服务商**；不同供应商未必支持该协议，可能产生费用，必须先验证供应商功能和收费说明。API 提交超时后不会自动重复付费创建；已有远端 ID 的恢复会优先查询而非重建。下载完成时先写入持久媒体记录，再加入文章，意外中断可复用本地文件，不重复生成播放器。模型视频与 FFmpeg 字幕视频互不混淆。

**原始证据核查（管理员手动发起）**：在具体原创文章的逐条事实主张界面，选择已经人工批准并启用的网站以及该网站上的原始资料链接。Agent 首先检查 robots.txt 和访问冷却、同域限制，然后受限读取最多 128KB 的 HTML/TXT 正文。管理员内部保存来源 URL、最多 3000 字符的核对节选、页面 SHA-256、核查时间、AI 对主张判断是「支持」「冲突」还是「不明确」。不自动转载到文章，也不抓取第三方图片和视频；禁止访问未批准网站、私有 IP、跨站重定向和绕过访问限制。该核查使用原网站真实文字作为线索，比仅搜索摘要更可追溯，但并不自动证明内容真实有效。编辑仍需检查资料权威性、发布日期和适用范围。

**部署及验收**：使用原安全更新命令 sudo bash bin/update.sh，保留每五分钟 CLI agent-run.php 调度；环境自检 php bin/agent-check.php 已增加视频提供商配置与队列状态。新功能默认关闭，仅管理员主动打开/提交。CI 模拟视频供应商和受控网页验证计费任务预算、原始来源隔离、文档冷却、证据记录、二进制 MP4 安全交付；实际视频供应商、中文生成画质及线上资料访问仍未实测。复杂 Mermaid/LaTeX 全覆盖和深层自动事实认证仍属于待完成的能力。

## Agent 富格式、逐条事实主张核查与原创视频增强（2026-11-06）

**复杂导图和公式**：不再局限于简单的线性流程图。对严格白名单内的 Mermaid graph TD/TB/LR/RL 有向无环图，可处理多个分支、决策节点、合流节点；分层显示全部节点，另外明确列出所有连接关系。对缩进型 Mermaid mindmap，生成层级化的可访问 HTML 树状图（不执行 Mermaid JavaScript、外部 SVG、链接宏或脚本）。节点、边和深度均有上限，复杂或不安全指令会退回 **原始可编辑源码**，而不是误画成另一张图。渲染属于结构保真，不是像素级 Mermaid 1:1。AI 生成的 mindmap **保留换行与缩进**，不再被普通文本规范化压平。

基础 TeX→MathML 的安全解析增加求和上下标、积分/乘积符号、少量文本标签以及有边界的 matrix / pmatrix / bmatrix / vmatrix（最多 8×8）。其他 TeX 宏仍只显示原始表达式，禁止动态加载任意宏包或脚本；完整 LaTeX 排版仍需后续独立渲染器。

**逐条主张与线索对应**：质量审稿模型针对新原创教程中的具体、可检验说法给出 up to 8 条审核清单，分别标记“有两个不同域名的索引摘要提供交叉支持线索”、“搜索摘要与主张冲突”或“未获佐证”；每条主张链接相应的**管理员内部**搜索索引记录。后台能查看按编号关联的站点摘要与具体疑点。不足两个不同域名的摘要不能标记为交叉支持；矛盾或证据不足时进入人工复核。**搜索摘要即使一致，也不能证明事实真实，不能称为事实已认证**。网站来源不会因此进入文章正文或被自动下载转载。

**原创 MP4 视频增强**：视频现在有按时间依次出现的章节标题与步骤、底部移动进度提示、淡入淡出。如果本篇已生成本站 AI 原创插画（本地 PNG/JPG/WebP），将用它作为字幕讲解画面背景，并使用暗色叠层保障文字可读；否则退回纯色背景。先生成插画再合成 MP4，避免顺序不一致。音轨仍可来自独立生成的 MP3。功能只合成本站原创教程的文字、步骤和画面，**不是模型生成的实拍动作、真实操作录屏或专业长视频动画**，最长仍为 10–25 秒。

**上线前自检**：

    php bin/agent-check.php

或在后台 **内容发现 Agent → 原创选题 Agent → 检测当前服务器的 Agent 环境与队列** 打开只读诊断。检查 PHP 扩展、FFmpeg、libx264、drawtext、中文字体、图片/私有媒体目录权限、AI 与搜索服务是否已配置、待审与待生成任务数。不发送凭据，也不主动请求外站或 AI 模型。服务器可先检查环境，再单独打开图像、视频、配音选项，逐项观察实际成功率。

自动测试覆盖 DAG/思维导图与非支持指令拒绝、矩阵和基础 TeX、逐条搜索线索与虚构编号拦截、真实 FFmpeg 原创图片背景视频、原有用户界面和上传权限。**仍未通过生产环境实测**：所配置的外部 TTS/图像模型、线上中文字体效果、实际播放与真实事实核验工作流。没有 GPU 也能在 FFmpeg 下合成短片，但大规模视频任务依然会消耗 CPU、内存和磁盘。

## 原创教程 Agent：二次质量审查和音视频输出（2026-11-06）

**第二次独立审稿**：每篇新原创教程由写作模型输出后另开审核任务，检查不安全操作、矛盾、未经证实的技术参数、模型和政策陈述，以及步骤可操作性。审稿模型只对草稿内容做风险筛查，**并不等于真实事实核验**。可选开启已配置的 Brave Search API 搜索索引摘要，获取最多 5 个不同域名的交叉检查线索；不请求对应网页、也不把来源素材发回写作模型或插入正文。全文出现在管理员内部审核列表；存在重大疑点时保持待人工复核。管理员可以输入至少 12 字的审核说明后人工放行，系统会记录事件；永不自动公开发布。

审稿额度默认 **8 次/24h**，搜索线索额度默认 **2 次/24h**，由 SQLite 原子计数并且失败也计入预算。搜索线索功能默认关闭；若无 API 密钥仍可开展仅 AI 内部质量审查。旧版已经处于审核队列的文章不会被迁移或丢失；新版创建的文章必须完成审稿或人工复核才能建立未发布草稿。

**独立原创配音**：可选为每篇新教程从其原创标题、步骤自动生成一段配音讲稿，并通过已配置的 OpenAI 兼容音频服务（POST /audio/speech，模型 ID 与音色 ID 由管理员指定）生成 MP3。前置：服务商真正支持兼容接口。原教程来源网址和旧文章均不用于转写，默认关闭。

**独立原创短视频**：可选仅从新生成的标题和几个要点合成 10–25 秒的 854×480、12fps、带中文字幕的 MP4 幻灯片，使用服务器本地 FFmpeg（需要支持 drawtext、libx264），存在原创配音时可尝试将其合入视频。**属于文字演示，不是实机操作录像，也不是 AI 摄像机生成的视频素材**；不下载或使用外站视频。每次视频任务最长执行约 100 秒，结果最大 18MB，配音 MP3 最大 5MB。中文字体需要安装 fonts-noto-cjk；若缺少组件，会标记失败，并可手动跳过任务继续审核。

配音和视频各默认 **2 次/24h**，功能均默认关闭。新文章只在创建时读取功能开关排队，已存在草稿不会突然重生成媒体。生成的素材保存在 HowHub 的私有附件目录，图片素材与音视频由不同管线管理，不暴露原始服务器路径。文章包含可用的 HTML5 播放器以及附件下载链接，播放接口限定本地受控 MP3/MP4，支持 HTTP Range（206/416），未发布时只有登录管理员可访问。

**宝塔依赖示例（Ubuntu）**：

    sudo apt-get install -y ffmpeg fonts-noto-cjk

实际可用性仍须确认服务器 PHP 安装及所选供应商的语音 API；上述配置不包含云端 GPU 或 AI 视频模型。安装前建议确认服务器资源空间，维护期间优先停用 Agent。后台入口：**内容发现 Agent → 原创选题 Agent**，可配置审稿和媒体额度、模型 ID、查看风险项、手动放行/重试/跳过。部署使用当前已有安全更新器和每五分钟 CLI 任务，不需要建立新的常驻服务。

**仍需验证/未完结**：运行服务器真实 TTS 模型的兼容性；中文字体的实际渲染效果；MP4 播放的端到端真实用户体验；事实级别的可靠跨网站佐证、复杂 Mermaid/思维导图/LaTeX 1:1 图形渲染、真实原创动画视频和长篇配音。CI 测试不能代替这些生产环境验收。

## 内容发现 Agent：标题/问题驱动的 AI 原创教程（2026-11-06）

**默认创作模式已更改为 topic_only。** Agent 通过配置好的 Brave Search API 获得搜索索引中的文章标题，并只从搜索摘要提取短问题；或者在遵守 robots.txt 和站点访问频率的情况下读取管理员批准的 RSS/Atom 中的标题与简短问答。**不再自动打开原文章链接获取全文、图片、视频**。搜索结果中的域名仍供管理员自愿审批；但从搜索结果标题提取的选题不需要为了写原创文章而访问该域名。

Agent 按标题/问题去重，AI 只接收选题及所属行业/语言，而非来源 URL 或正文。AI 从零生成**新的中文标题、原创解释、可操作步骤、表格、TeX 公式与 Mermaid 简单流程图**；输出经过 HTML 安全过滤、质量和长度检查，待管理员审核后方可建立未发布草稿，绝不自动公开发布。

**可选原创插画**：在后台「原创选题 Agent」配置支持 OpenAI 兼容图片生成接口 /v1/images/generations 且返回 b64_json 的图像模型。每篇最多生成一张新概念图，校验后转存本站本地媒体库。模型未配置或失败就跳过，不回退下载外部网站的图片。独立 AI 长视频或音轨生成本版尚未完成；当前“多模态”明确支持图文/表格/公式/流程图和可选原创插画，不包含视频复刻。

**公开出处**：此新模式生成的是基于标题/问题的全新独立内容，不用来源正文或多媒体，因此**不会将第三方来源、作者或版权声明显示在原创文章正文中**。选题出处和发现方式仍保存在管理员专用数据库中以便审计、申诉、去重与事实核实，不会泄露给正文写作 AI 或公开给读者。既有旧版来源摘要和授权原件的草稿不会被修改或删除其原有出处记录。

**启用**：按项目的安全更新流程运行 sudo bash bin/update.sh，再访问 /admin/agent，启动总开关、配置 AI 供应商和可选的自动找站/图片模型，保持已有的每 5 分钟 CLI 定时任务。可以直接人工填写标题/问题加入原创队列。开启自动找站后，搜索 API 结果标题会自动进入选题队列；来源 RSS 必须先批准并遵守站点频率策略。

**准确性与合规边界**：只抽主题并自行创作可减少直接复制第三方作品的风险，却不能推断为“无需遵守版权、服务条款、API 协议或其他法律”。访问 RSS 仍遵守 robots、低频和停止规则；不得绕过登录、付费墙或站点禁止访问指示。生成文本、教育图解和步骤仍需人工检查事实、安全性及是否不当复刻受保护内容。

## 管理员登录与诊断锁修复（v0.8.6）

实际 PHP-FPM slowlog 发现登录请求在 `diagnostics.php:87 flock()` 阻塞，Nginx 中出现 HTTP 499。诊断事件改用非阻塞日志锁；当有其他进程持有日志锁时跳过本条日志，任何诊断失败均不得阻碍业务请求。登录成功后先写入并关闭 PHP Session，再更新登录时间、记录日志及重定向；失败/限流也先保存会话状态再写日志。CI 增加独立进程占用锁时的单元测试与 HTTP 登录验证。此修复不重置账户和数据。

## 安全更新、自动备份与失败恢复（v0.8.1）

**今后不要再直接运行 `git pull` 更新线上 HowHub。** 统一通过 `sudo bash bin/update.sh` 完成：串行更新锁 → 检查远端 main 是否可快进 → 临时维护状态 → 用 SQLite `VACUUM INTO` 生成包含已提交 WAL 内容的一致性数据库快照 → 备份整个 `storage/`（AI 密钥、附件、诊断日志、其他私有数据）和 `public/uploads/`（图片）→ SHA256 校验 → 代码快进 → PHP 语法、启动、SQLite 完整性检查。成功后继续保留最新备份，不恢复旧内容；**失败自动回滚到旧 Git 提交并恢复数据库、附件、图片和密钥**。失败期间产生的数据另存在备份文件夹 `failed-live-storage/` 和 `failed-live-uploads/`，避免静默销毁。

默认备份目录 `/root/howhub-backups/`（仅 root 可读写）；自动保留最近 **7 次成功更新**的备份，失败/回滚备份不会自动删除。需要保留更多可在调用前设置 `HOWHUB_BACKUP_KEEP=15`。如果磁盘可用空间不足，更新会在备份前停止。无新版本则不重复备份。无需额外数据库、Node 或 Docker。

### 首次启用自动更新器（当前服务器还没有脚本）

旧版本尚不包含更新脚本，为了让**第一次升级也先备份**，在服务器终端执行：

```bash
cd /www/wwwroot/howhub.k2n.cn/HowHub
git status --short
# 若有跟踪文件修改，先处理再继续
git fetch --no-tags origin refs/heads/main:refs/remotes/origin/main
git show origin/main:bin/update.sh > /tmp/howhub-update-once.sh
sudo env HOWHUB_ROOT="$PWD" bash /tmp/howhub-update-once.sh
rm -f /tmp/howhub-update-once.sh
```

这个引导流程先从已连接的 GitHub SSH 仓库取出最新更新器本身，**不会提前用 git pull 修改线上代码**。使用前确认远程仓库是 `b8vipvip/HowHub`。从此以后执行：

```bash
cd /www/wwwroot/howhub.k2n.cn/HowHub
sudo bash bin/update.sh
```

注意：首次从尚未支持维护标记的旧版本升级时，应避开正在上传素材、保存文章或进行 AI 长任务的时段；新版本会在 `storage/.maintenance` 存在时返回 HTTP 503，避免后续升级时产生新的写入。已在运行的旧请求无法由维护标记直接中断，因此仍应尽量选择空闲时段。

安全说明：自动恢复仅在脚本内的升级验证失败时触发；它不可能自动判断所有上线后才被发现的业务逻辑问题。对于被强制中止（例如断电、SIGKILL）且留有维护标记的情况，脚本会拒绝重复更新，须先检查备份和现场并由管理员处理。常规成功升级不能再恢复旧数据，否则会覆盖升级后新增的教程。

## 宝塔面板正式部署（howhub.k2n.cn）

### 一、环境

1. 在宝塔安装 **Nginx** 和 **PHP 8.2 / 8.3 / 8.4**（推荐 8.3）。
2. 在 PHP 的扩展管理中开启 **PDO SQLite / SQLite3、mbstring、dom（XML）、fileinfo**。需要同时具备 `pdo_sqlite`、`mbstring`、`dom`、`fileinfo` 模块。某些宝塔版本 SQLite3 包会提供 `pdo_sqlite`，以 `php -m` 实际结果为准。
3. 确认宝塔已有站点 `howhub.k2n.cn`，并且 DNS 解析正确。HTTPS 证书在宝塔站点「SSL」里申请后开启强制 HTTPS。

### 二、克隆项目

在 Ubuntu SSH / 宝塔终端操作（不改动其他站点）：

```bash
cd /www/wwwroot/howhub.k2n.cn
git clone https://github.com/b8vipvip/HowHub.git HowHub

# 数据目录与图片目录必须允许 PHP-FPM 的 www 用户读写
sudo chown -R www:www /www/wwwroot/howhub.k2n.cn/HowHub/storage /www/wwwroot/howhub.k2n.cn/HowHub/public/uploads
sudo chmod 770 /www/wwwroot/howhub.k2n.cn/HowHub/storage
sudo chmod 775 /www/wwwroot/howhub.k2n.cn/HowHub/public/uploads
```

若你的站点文件夹不是上述路径，按宝塔真实路径调整；如宝塔 PHP 运行用户不是 `www`，请替换为实际运行用户。

### 三、配置网站运行目录与 URL 重写

1. 在宝塔 **网站 → howhub.k2n.cn → 网站目录 → 运行目录**，将其设置为：

   `/www/wwwroot/howhub.k2n.cn/HowHub/public`

   **不能指向 HowHub 项目根目录**，否则配置、数据库目录可能暴露。
2. PHP 版本选择已经安装扩展的 PHP 8.2+，不要选「纯静态」。
3. 宝塔 **伪静态** 规则使用：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
location ^~ /uploads/ {
    try_files $uri =404;
}
```

   保留宝塔原有的 PHP-FPM 转发配置，不要复制第二份 `location ~ \.php`。`/uploads/` 使用 `^~` 防止文件被 PHP-FPM 解析（PHP 上传接口仅允许真实图片）。
4. 保存配置并在宝塔「配置文件 → 检查配置」确认 Nginx 检查通过，随后重载。

### 四、创建初始管理员（没有默认密码）

宝塔 PHP-CLI 路径一般如下；实际路径根据 PHP 版本调整：

```bash
cd /www/wwwroot/howhub.k2n.cn/HowHub
PHP=/www/server/php/83/bin/php

# 先确认 CLI PHP 扩展齐全
$PHP -m | grep -Ei 'pdo_sqlite|mbstring|dom|fileinfo'

# 以网站运行用户执行，避免数据库文件被 root 独占
sudo -u www "$PHP" bin/create-admin.php admin
```

输入一个至少 **12 位**的管理员密码。创建后登录：

- 前台：`https://howhub.k2n.cn`
- 后台：`https://howhub.k2n.cn/admin/login`
- 管理员：`admin`（密码为刚刚创建的密码）

初始化无需运行 SQL 文件；数据库及内置首篇教程首次访问时自动创建。

### 五、转存首篇教程配图（建议）

语雀 CDN 图片初始使用原始外链。如果服务器能够访问这些 URL，运行下面的可选迁移脚本，把 5 张图转存本站，避免源图失效：

```bash
cd /www/wwwroot/howhub.k2n.cn/HowHub
sudo -u www /www/server/php/83/bin/php bin/import-yuque-images.php
```

脚本只会下载内置首篇教程的 **5 个固定 CDN URL**；逐个检查大小、PNG 文件头，成功的图片改成本地引用，失败的保持原链接，不会损坏文章。后续新教程通过后台直接上传图片，自动保存在本站。

### 六、检查与更新

```bash
curl -fsS https://howhub.k2n.cn/healthz
# 预期：{"ok":true,"app":"HowHub"}

# 后续更新统一通过自动备份与失败回滚工具

```

**重要：** `storage/howhub.sqlite` 及 `public/uploads/` 在 `.gitignore` 中，不会被 Git 更新覆盖。上线后要在宝塔「计划任务」中每天备份这两个目录（包含 storage/media_files 附件），SQLite 数据备份建议用 `sqlite3 ... '.backup ...'` 或停写/快照方式，切勿在写入期间仅复制单一 `.sqlite` 而忽略 WAL 文件。避免给 `storage` 开启公开下载。

- **粘贴网页源码交给 AI**：在正文上方「导入网页图文教程」区域粘贴原始 HTML 或语雀 `ne-viewer-body / ne-card` 代码，点击「AI 解析并创建文章草稿」。支持聊天复制时带 `\\<div>`、`https\\://` 的转义形式；会解析标题、步骤、文字及 `<img>` 配图，给每个原始图片地址分配固定 `[[IMAGE_N]]` 占位符。AI 只决定文章内容和占位符位置，后端将图片安全替换为原始地址，不允许模型制造未经来源确认的图片 URL。生成后自动在 SQLite 中创建**新的、未公开的草稿**并跳转到编辑页；不会覆盖当前在编辑的已发布文章。
- **AI 服务端配置**：登录后台 →「AI 供应商」→ 输入与 mv3c 一致的 chat2api OpenAI 兼容接口地址（如 `https://your-chat2api.example/v1`）、API Key、模型 ID → 保存 → 可点击「从供应商发现模型」调用 GET `/v1/models`。文章导入调用 POST `/v1/chat/completions`，使用非流式 Chat Completions，避免改动原 chat2api 或 mv3c 运行环境。外网地址需 HTTPS，内网/本机地址允许 HTTP。调用失败不创建草稿，不自动重试以避免重复扣费。

**注意：** HowHub 的供应商凭据不直接读取 mv3c 的数据库，也不会自动同步 mv3c 里的密钥；管理员需在 HowHub 后台独立配置相同的服务商。API Key 仅存于服务器 SQLite 中的 AES-256-GCM 密文，解密密钥位于项目非公开的 `storage/ai-secret.key`（`0600`），或可设置 `HOWHUB_AI_SECRET_KEY` 64 位十六进制环境变量。备份数据库时务必一并备份这个密钥文件，否则无法解密原有配置。不要把任何密钥提交到 GitHub。

运行环境额外需要 PHP `curl` 和 `openssl` 模块（除原有 `pdo_sqlite / mbstring / dom / fileinfo` 外），PHP-FPM 与 Nginx 的读写超时应按模型耗时合理设置（AI 调用最多等候 180 秒；可在宝塔站点 PHP-FPM / Nginx 配置中设为略高于 180 秒），否则浏览器可能在服务端完成前收到 504。代码和网站当前**不会运行定时/后台 AI 任务**。

AI 仅接收手动提交的网页源码/文本及图片占位符，不会自行抓取外站页面或识别原始图片内容。**AI 生成 HTML 后，HowHub 服务端会尝试下载原文已有 URL 的图片、校验格式并保存至素材库，再将 HTML 图片地址替换为本站 `/uploads/`。**不会自动保存教程。如外链无法下载，编辑器会显示失败数及原因，失败图片继续保留原始地址；源 HTML 中缺少任何可解析图片地址的懒加载图片会拒绝导入，要求先加载完整图片后再复制。带验证码、支付信息、账号密码等敏感资料的网页内容需先移除这些信息后再提交 AI。

### 一键链接导入：网页 / 文档 / 图片 / 视频（2026-11）

在 **新建教程 / 编辑教程** 顶部使用 **「只粘贴一个网页、文档或视频链接」**：输入公开链接 → 解析格式 → AI 判断是否为可验证的攻略、教程或方法 → AI 流式生成 HTML → 转存可用素材 → 填入源码编辑器。不会自动保存、覆盖文章或发布；非教程或证据不足直接拒绝。

- **网页：** HTML/XHTML 及通用 CMS 图文页面，解析正文、图片、相对链接、来源信息。
- **文字与文档：** TXT、Markdown、JSON、XML、可提取文字的 PDF、DOCX、PPTX、XLSX。可用的原文件作为私有下载附件存储于 storage/media_files/，并在教程正文附上原件下载链接。扫描 PDF 不自带 OCR。
- **图片：** PNG、JPEG、WebP、GIF 直链。校验并转存原图，由配置好的支持视觉理解的 AI 分析可见操作信息。
- **视频网页：** 优先处理公开网页字幕、JSON-LD 及发布者步骤说明。安装 yt-dlp 后对部分公开平台视频（YouTube、哔哩哔哩、抖音、TikTok、Vimeo）尝试获取字幕；不绕过登录、付费或版权限制。平台视频原文件不保证可转存，保留来源链接与可用封面。
- **视频文件：** MP4、WebM、MOV 公网直链（上限 30MB），需要 FFmpeg 抽取关键帧，并由支持 image_url 多模态输入的 AI 理解可见操作。原视频安全归档为私有下载文件；最多抽取 4 帧。抽帧不等于音轨转写，缺少字幕或可识别画面时拒绝编造步骤。
- **安全：** 管理员登录和 CSRF 验证；DNS 公网校验、地址固定解析、逐跳重定向验证、非标准端口拒绝、下载大小及超时限制；AI 分类先于 HTML 生成，失败与取消会清理本次未交付素材。
- **限制：** 5 次链接导入/10 分钟（按管理员会话）；源文件 30MB 上限，网页 HTML 不超过 2MB，单张图片 6MB。动态加载、反爬、登录页、加密或无可靠字幕的媒体不保证可导入。仍可以粘贴原网页 HTML 手动导入。

按需要安装可选服务器依赖：poppler-utils（pdftotext）、PHP zip 扩展或 unzip、ffmpeg、yt-dlp。没有依赖时会显示错误提示，绝不谎称已分析视频音轨。图片与视频帧理解还要求 chat2api 模型支持 OpenAI 兼容图像输入。链接导入包含分类和生成两次 AI 调用，PHP-FPM/Nginx 读取超时需按实际模型执行时间配置。更新前备份 storage/ 和 public/uploads/，不需要变更 mv3c。


### 通用 HTML 导入引擎（2026-11）

在教程编辑页的 **「导入网页图文教程」** 填入 HTML；如果含有相对图片、相对链接，额外输入 **「原网页 URL」**。点击 **「AI 生成 HTML 并填入下方编辑器」** 后：

1. 不依赖具体 CMS 名称；解析文章主体和自定义 DOM 元素，并识别 `src`、`data-original`、`data-src`、`srcset`、`picture/source`、常见背景图片属性及内嵌 Base64 位图。
2. 将相对地址结合源网页 URL 还原成完整 URL；图片与超链接采用 `[[IMAGE_N]]`、`[[LINK_N]]` 固定占位符发送给 AI，AI 不接触图片原始二进制，也不能自行改变原始链接。
3. 检查生成结果中图片与链接的数量、顺序和真实地址；拒绝漏图、漏链接、伪造图片或新链接，失败不覆盖编辑器内容。
4. 将来源为公网 HTTP(S) 的原图尝试转存至本站素材库（限制 6MB/张），本地图片地址替换为 `/uploads/`；如下载失败保留外链并展示失败数量和原因。Base64 位图同样会校验并入库。
5. AI 生成后只填入 HTML 源码编辑器，不自动保存、覆盖已发布内容或发布文章；需要管理员预览和手动保存。

**边界：** 静态 HTML 不会执行 JavaScript，也不会抓取远程网页本身；仅靠 HTML 无法还原运行时才生成的 DOM、Blob、canvas、嵌入内容以及部分不可见/未加载图片。遇到缺失图片 URL 或不可解析的相对链接时会直接提示；无法恢复的嵌入内容会作为警告显示。单次最多 300KB 原文、60 张图片、100 个文本超链接、90000 字符提取正文。大图或复杂动态页面应先在浏览器加载完整资源后再复制 HTML。该流程针对可提取图文和链接完整性，不保证 AI 改写的每个自然语言句子与原文逐字一致。

**CI 回归：** `php tests/smoke.php`、`php tests/universal_import.php`、`bash tests/e2e.sh`。图片转存到服务器需要服务器能访问外站 CDN、且 `public/uploads/` 可写；GitHub CI 不代表真实公网图片都能成功下载。

## 内容发现 Agent：自动找站、透明出处及安全富内容预览（2026-11-06）

**自动找站**：/admin/agent 新增「AI 自动寻找国内外知识来源网站」。默认关闭。启用后，CLI 调度器可以轮换 12 个跨行业、跨语言主题（管理员可以新增/暂停/删除），让 AI 生成检索词，再通过已配置的 Brave Web Search API 查找实际搜索结果中的域名。没有搜索 API 密钥时，使用已配置的 AI 推荐网站，但所有域名均标记为 **未联网核实**，可能不存在。搜索 API 证据不证明抓取许可或版权。新增的站点仅进入**人工审核的来源候选**，批准后依旧默认暂停、仅原创摘要模式，管理员检查站点条款并手动启用后才会触发原有 robots 和低频调度逻辑。

- Brave Search API 密钥只在后台录入，通过已有 AES-GCM 凭据加密逻辑存储，不明文显示或写入诊断日志。官方服务提供独立订阅和计费；不提供密钥则不访问搜索网站，也不模拟抓取搜索引擎结果。
- 搜索/AI 推荐单独限速：**每 24 小时最多 4 次，单个研究主题再次搜索至少间隔 72 小时，每次定时调度最多一次外部请求**。来源池已有任务时仍会定期插入研究任务，每约 6 小时最多一次，不会频繁重复发起。
- 可编辑、独立保存的行业语言主题支持中文、英文、西语、法语、德语、日语、韩语、葡语和其它语言。默认主题只在首次建库时创建，删除后不会自动恢复。

**文章开头强制出处声明**：新生成 Agent 候选正文最前面，自动注明原始网址、站点名称、来源原作者（如果网页提供）、原文日期、网站公开声明的许可链接（如果提供）、AI 整理或改写说明、事实尚待复核以及「注明出处不等于获得转载许可」。公开的许可声明只是页面元数据，**不会自动激活转载或媒体转存权限**。来源摘要模式仍不复制未获许可的图片视频。候选详情永久保存可核查的来源快照；建立草稿后即便管理员编辑文章而误删来源区块，保存时也会自动恢复同一来源区块。旧版 Agent 草稿也可以通过已有来源 URL 自动补全出处。

**保真渲染进度**：保留安全 HTML 表格及 colspan/rowspan；对浏览器原生 MathML 与常见 TeX 简式（如分数、开方、上下标、基础希腊字母）增加**无外部 JS**的数学展示，并保留可编辑公式源码。对**无分支的简单 Mermaid 线性流程图**提供静态近似预览并保留原始图定义。复杂 LaTeX 宏、Mermaid 分支流程、SVG、Canvas 和第三方动态导图仍不能宣称 1:1，保持原始定义和警示，避免生成误导性图形。所有标签仍通过统一 HTML 白名单过滤。

**视频音轨（可选，默认关闭）**：针对有明确授权的直链 MP4/WebM/MOV 视频，支持在 FFmpeg 可用且现有 AI 供应商支持 OpenAI 兼容音频转写接口时，提取并发送**前 90 秒**的单声道音轨供模型转写。必须在后台显式开启并配置模型 ID，失败时自动回退到已有视频抽帧路径并标明音轨未理解。此功能不保证解析整段长视频、外站受保护视频或音轨准确性；外部 AI 可能接收视频语音内容，开启之前必须核实授权及适用的数据处理规则。

**限制和部署**：功能默认关闭，不自动搜索或采集。服务器更新后在 /admin/agent 开启内容发现总开关与「自动找站」，并在宝塔安装原有的每五分钟 CLI 调度任务。管理站点来源仍需逐个批准；申请 Brave Search API 订阅可进一步减少 AI 幻觉域名，AI 无权判断爬虫或转载许可。建议先在关闭采集的环境检查新增后台页面、来源声明与 HTML 表格/公式/导图预览，再逐站试运行。此功能受原有 AI 接口、网络、PHP、FFmpeg 和字幕/转写模型能力约束。

## 内容发现 Agent：全球知识 / 教程 / 问答审核管线（2026-11）

后台入口：**内容发现 Agent**（/admin/agent）。新增独立的、**默认完全关闭**的发现模块；每个新来源同样默认暂停。管理员配置允许访问的 HTTPS 站点、该站的 RSS/Atom/Sitemap 地址、行业领域、国家/语言，然后手动启用来源及全局开关。国外网站、各种行业都按相同的权限和频率管理；不会自动对陌生域名进行广域无边界爬取，也不会绕过机器人访问限制。

### 自动处理链路

1. 每轮定时任务只执行 **一个**站点操作；先获取并缓存约 24 小时的 robots.txt（这次请求也计入站点配额），匹配 HowHubDiscoveryBot 和 * 的 Allow/Disallow 规则。robots 无法确认、401/403、5xx 会暂停；404/410 按标准视作该文件不存在。对 robots 明确禁止的路径不访问。即使 robots 允许，也必须核对来源条款/版权。
2. 从手动指定的 RSS、Atom 或 Sitemap 发现同一站点的最多 20 个新候选；对 URL 做规范化去重，禁止跨域扩散、跳过账户/支付/搜索页面。内容页面如跳转到别的 URL，需重新检查目标 robots，Agent 不会自动跟随。
3. 严格频率：**默认每来源两次访问之间至少 1800 秒、每 24 小时最多 8 个请求、全局最多 40 次、同一普通页面至少隔 48 小时**。管理员可以调低速度（最短 300 秒、单站最高 20/24h），遵守 robots 里更长的 Crawl-delay。请求通过 SQLite 立即事务原子预留、单次 CLI 全局进程锁防并发。
4. 优先读取公开 HTML/文字/PDF；遇到响应头或页面中的 noindex、nosnippet、noarchive、noai 则跳过。AI 对中文和国外知识内容做事实证据线索、实用性、行业评分，输出短篇**原创中文摘要、重点、需进一步核实的内容、原始网址**。低质、重复或无根据内容拒绝。AI 不等于独立事实核验。
5. **全部进入人工审核队列，永不自动公开发布**。管理员查看来源、原始链接、评分、内容与多媒体状态，确认后才会进入 HowHub 原有未发布草稿，仍需人工点击正式发布。
6. 无明确授权时，**仅生成带来源链接的原创摘要，不复制第三方整篇文章、不转存媒体**。只有管理员留下明确的转载许可/作品授权证据，并选择许可模式，Agent 才会尝试保留表格等源结构，并将**同一已授权站点**上的图片加入单独低频转存队列；每次仍只处理一张图片并遵守 robots、域名和配额。未明确许可的第三方 CDN 图片不会自动镜像。
7. 可编辑结构：已许可内容的 HTML 表格（包含有限的 rowspan/colspan）、公式的原始表达式（代码块）以及 Mermaid/PlantUML/Graphviz 等图表定义（代码块）可保留；静态图片可依授权转存。**现版本不能保证复杂数学公式/导图的图形 1:1 排版**，SVG、Canvas、JS 动态图表会警告并要求后续专用渲染器。不能把源码保存误报为视觉还原已完成。

### 服务器调度

HowHub 使用 PHP 8.2+ 与 SQLite，不需要常驻 Agent 服务。请先更新站点，再在宝塔「计划任务」中添加 Shell 命令，周期设为**每 5 分钟**：

    /usr/bin/php /www/wwwroot/howhub.k2n.cn/HowHub/bin/agent-run.php

也可在服务器手动执行一次该命令查看 JSON 结果。使用单进程文件锁防止重复任务。**安装定时任务不会自动启用采集**：管理员仍必须在 /admin/agent 开启全局开关、手动批准各来源和源站条款。如果关闭全局开关，调度返回 disabled，不访问网站。不会修改已有文章。诊断日志以及 Agent 自己的审计表均记录处理结果。

**版权和法规提示**：robots.txt 是自动访问偏好的约定，不代表转载授权；网站服务条款、图片/视频版权、CC 许可中的署名、商业使用/改编限制、地区法律等仍适用。应优先使用有明确开放许可的官方知识库、授权 API 或自有来源。全球无差别抓取、抓取搜索引擎结果、跨域自动扩散、代理轮换、破解验证码等均不在此 Agent 中实现。无法用代码保证第三方不会将访问视为违规。任何内容上线前都需人工核对事实与许可。

运行前建议：备份 storage/ 和 public/uploads/；确认站点 PHP 有 curl、dom、mbstring、pdo_sqlite 扩展且所选 AI 供应商可访问。可用的外国来源语言不限；但外部访问可能因网站拒绝、超时或网络连接被阻止。对视频等复杂链接仍保留后台的**单链接手动导入**流程，自动发现阶段不会绕过付费墙或批量下载视频。

## HTML 源码编辑、实时预览与 AI 优化（v0.4）

登录后台并打开任意一篇文章的编辑页：

- **`</> HTML 源代码`**：在可视化与 HTML 源码模式之间切换。源码修改会参与保存；切换回可视化时调用 `/admin/import/clean` 安全清理 HTML，不会暗中保存。
- **预览当前内容**：安全过滤当前未保存的 HTML，在受限 `sandbox` iframe 中展示文章效果。关闭预览不修改文章、不发布。
- **✦ AI 优化**：将**当前编辑器里的正文**（包括未保存的修改）交给「AI 供应商」中配置的 chat2api 模型进行段落、措辞、颜色、提示样式及图片尺寸优化，结果直接写入 HTML 源码区。由管理员自行检查、预览、点击「保存教程」才会写入数据库。
- **撤销 AI 优化**：不保存的情况下可将本次结果恢复为调用前的内容；若已保存，可从备份恢复。
- 优化对原有图片采用服务器端占位符：原图地址、数量、顺序不得丢失或改变；原有超链接地址也必须完整保留。未通过校验的 AI 输出会被拒绝，不影响原文章。
- 仅允许安全的颜色、字体、对齐、图片宽度和专用提示框类名；`script`、事件属性、危险 CSS、外部样式表等会被过滤。**不是无限制 HTML/CSS 编辑器**。
- 优化请求使用后台 CSRF 与 10 分钟 6 次的会话限额；当前正文会发送给你配置的 AI 服务。**不会自动保存和公开发布。**

> 宝塔部署更新前务必备份 `storage/` 和 `public/uploads/`，并保留 `storage/ai-secret.key`；Git 更新只覆盖受版本控制的代码文件。编辑器资源若未刷新，可在浏览器按 `Ctrl+F5` 强制刷新。

## AI 真实流式进度（v0.6）

- 在「AI 导入网页教程」和「AI 优化」时显示实时进度面板、已等待秒数、接收字符数和 AI 增量输出（只显示纯文本，不执行模型生成的 HTML）。
- 从 chat2api 调用 `POST /v1/chat/completions` 且 `stream: true`，服务端通过 `text/event-stream` 边接收边传给编辑器（不再等待完整 AI 响应）。
- 支持一键取消；没有收到最终 `complete` 事件时**不**应用 AI 优化，**不**写入部分草稿。原有非流式兼容接口仍保留。
- 流式阶段包括连接中、等待首个输出、正在生成、校验结果、保存草稿（或安全应用至源码模式）；等待期间的动画不表示虚构的完成百分比。
- 首次部署请确认 PHP `curl`、`openssl` 可用。Nginx 会收到 `X-Accel-Buffering: no`；如果仍在最后一刻一次性展示，检查宝塔 Nginx/PHP-FPM 是否额外缓冲输出。
- 对长任务检查网站所用 Nginx `fastcgi_read_timeout` 与 PHP-FPM `request_terminate_timeout`：至少能覆盖所配置的上游 Worker 最大执行时长。HowHub 的 cURL 最长等待 660 秒。默认 PHP 进程会被请求占用，建议限制同时发起的 AI 请求。
- 诊断日志只记录流式调用结果、时长、状态码与输出长度，不保存用户提交的网页代码或模型回复。
